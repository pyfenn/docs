Welcome to fenn's documentation!
=================================

 Friendly Environment for Neural Networks (**fenn**) is a simple framework that 
 automates ML/DL workflows by providing prebuilt trainers, templates, logging, configuration management, and much more. 
 With fenn, you can focus on your model and data while it takes care of the rest.

.. code-block:: bash

   pip install fenn
